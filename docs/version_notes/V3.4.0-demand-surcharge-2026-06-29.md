# V3.4.0 Demand Surcharge Update - 2026-06-29

## 背景

FedEx 需求附加费文件更新为 `FEDEX需求附加费-2026.6.29日更新.pdf`，本项目只采用“中国大陆出口的国际货件”口径。

## 主要变化

- 旺季附加费生效日期更新为 `2026-06-29`。
- IP 和 IE 分别使用对应旺季费率。
- 美国和波多黎各、加拿大、墨西哥、拉丁美洲：IP 为 `5.4 CNY/kg`，IE 为 `4.0 CNY/kg`。
- MEISA 拆分为第 1 组和第 2 组：第 1 组 `11.2 CNY/kg`，第 2 组 `17.4 CNY/kg`。
- 每票最低收费继续按 PDF 脚注使用 `1.80 CNY`。

## 不包含范围

- 不使用 ImportOne、G3P 或进口货件费率。
- 不改变 FedEx IP / IE 基础运费协议价。
- 不改变燃油费和汇率逻辑。

## 校验重点

- 美国 10kg：IP 旺季附加费 `54.00 CNY`，IE 旺季附加费 `40.00 CNY`。
- 德国 10kg：IP / IE 旺季附加费均为 `80.00 CNY`。
- 肯尼亚 10kg：MEISA 第 2 组，IP / IE 旺季附加费均为 `174.00 CNY`。
