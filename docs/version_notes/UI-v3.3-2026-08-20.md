# UI v3.3 - 2026-08-20

## 范围

- 视觉与信息结构以用户提供的 A 版参考图为主验收标准。
- 只调整页面展示和旺季附加费数据，不重写 IP / IE 协议价、Zone 匹配或基础运费计算逻辑。
- 本版本通过 GitHub `main` 分支发布，由 Vercel 自动部署生产网页。

## 旺季附加费

来源只读取 `需求附加费-2026.9.2生效.pdf` 第 1 页“中国大陆出口的国际货件”。

| 区域 | CNY/kg |
| --- | ---: |
| 澳大利亚和新西兰 | 2.10 |
| 关岛和日本 | 2.10 |
| 马来西亚 | 1.30 |
| 越南 | 0.00 |
| 其余亚洲国家和地区 | 1.30 |

其他区域继续沿用该页对应出口费率；美国、加拿大、墨西哥和拉丁美洲仍区分 IP / IE。

## UI

- Header 保留标题、v3.3、数据参考和更新说明；移除反馈入口。
- 左侧默认显示目的地、国家/地区手输、匹配状态、实际重量和三个计价参数。
- 右侧 IP / IE 完全对称，不显示推荐、时效或决策建议。
- 费用明细和计算公式默认公开；审计信息移入右上角“数据参考”。
- 免责声明和使用统计保留在页面底部。
- 页面整体密度压缩，费用明细与计算方式采用紧凑并列布局。
- 额外冗余以百分比输入和金额明细展示，默认 10%，内部仍等价于原冗余系数 1.10。
- 计算方式区域补充旺季附加费日期、燃油周期和燃油构成。
- 页面主体居中收紧，标题放大下沉，左右面板等高且右侧明细区域纵向填充。
