# V3.5.0 Demand Surcharge Update - 2026-09-21

## 背景

FedEx 中国大陆需求附加费文件更新为 `FEDEX旺季附加费-2026.9.21日起生效.pdf`。本项目直接采用最新版本，只使用“中国大陆出口的国际货件”口径。

## 主要变化

- 澳大利亚、斐济、新西兰：IP / IE 均为 `3.5 CNY/kg`。
- 美国和波多黎各、加拿大、墨西哥、拉丁美洲和加勒比地区：IP 为 `13.9 CNY/kg`，IE 为 `8.4 CNY/kg`。
- 以色列、欧洲：IP / IE 均为 `12.5 CNY/kg`。
- 印度：IP / IE 均为 `0.8 CNY/kg`。
- 斐济从普通亚洲区调整到澳大利亚、斐济、新西兰费率组。
- 每票最低收费继续为 `1.80 CNY`。

## 不包含范围

- 不使用 ImportOne 或 G3P 费率。
- 不改变 IP / IE 基础运费、燃油费、冗余和汇率逻辑。
- 不保留 2026-09-02 费率切换逻辑，生产数据直接使用本版本。

## 校验重点

- 美国 10kg：IP `139.00 CNY`，IE `84.00 CNY`。
- 斐济 10kg：IP / IE 均为 `35.00 CNY`。
- 英国 10kg：IP / IE 均为 `125.00 CNY`。
- 印度 0.5kg：按最低收费计为 `1.80 CNY`。
