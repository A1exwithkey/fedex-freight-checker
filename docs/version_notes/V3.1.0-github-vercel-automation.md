# V3.1.0-github-vercel-automation

日期：2026-06-15

## 本版目标

把 Vercel 网页从一次性手动部署快照，整理成可长期维护的 GitHub / Vercel 自动部署项目。

## 主要变化

- 网页版本升级为 V3.1。
- 网页版本日期更新为 2026-06-15。
- 燃油费更新为 2026-06-15 至 2026-06-21：
  - FedEx 官方燃油费：43.00%
  - 内部冗余：3.00%
  - 工具默认燃油费：46.00%
- `vercel_app/` 作为 Vercel 网页主目录纳入 Git 管理。
- 长期自动更新链路调整为：

```text
Cloudflare Worker
  -> GitHub: vercel_app/data/rate_config.json
  -> Vercel Git 自动部署
  -> 线上网页显示新燃油费
```

## 验收标准

- `npm run smoke` 通过。
- `npm run build` 通过。
- Cloudflare Worker 语法检查通过。
- GitHub 中存在 `vercel_app/data/rate_config.json`。
- Vercel 项目连接 GitHub，Root Directory 为 `vercel_app`。
- 线上网页顶部显示 V3.1 和当前燃油适用周。

## 仍需人工确认

- Vercel 后台是否已连接 GitHub 仓库。
- Cloudflare Worker 是否已部署最新版。
- Cloudflare Secret 中 `GITHUB_TOKEN` 是否仍有效。
